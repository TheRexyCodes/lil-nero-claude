# Lil Nero for Claude

[Lil Nero](https://lilnero.com) is an AI content strategist for YouTube, X, Instagram and Threads creators. This plugin adds the `/hey-nero` command and connects Claude to the Lil Nero server (`https://mcp.lilnero.com/mcp`).

## Install

In Claude Code:

```
/plugin install lil-nero --marketplace TheRexyCodes/lil-nero-claude
```

Then run `/mcp` and sign in with your Lil Nero account. In Claude on the web, desktop or mobile, add the connector `https://mcp.lilnero.com/mcp` from Settings → Connectors instead.

For platform research, install the Lil Nero Chrome extension from [lilnero.com](https://lilnero.com) and click Connect in its side panel.

## Use

```
/hey-nero what should I post this week?
/hey-nero why did my last video flop?
/hey-nero find outlier videos about AI coding
/hey-nero fix this title before I post: ...
```
